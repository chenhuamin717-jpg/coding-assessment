#  Deadline Monster
Deadline Monster is a simple arcade-style game made with Microsoft MakeCode Arcade. The game is about procrastination, digital distractions and deadline pressure.

# General Information
Deadline Monster is a videogame about deadline pressure and digital distractions.
The player needs to collect five study tasks before the countdown reaches zero. The player also needs to avoid a phone, TV and game console.
The Deadline Monster represents deadline pressure. It becomes bigger as the remaining time gets lower.
# Technologies Used
- Microsoft MakeCode Arcade
- Block-based coding
# Features
- The player collects five study tasks.
- The player avoids a phone, TV and game console.
- The game uses a 45-second countdown.
- Touching a distraction reduces the remaining time.
- The Deadline Monster becomes bigger as the time gets lower.
- The Monster starts chasing the player during the last 15 seconds.
- The game uses sound effects for tasks and distractions.

# Setup
- Download the arcade-Deadline-Monster.uf2 file from this repository.
- Open Microsoft MakeCode Arcade and import the project file to view or edit the game.
# How to Play
- Use the arrow keys to move the player.
- Collect five study tasks before the timer reaches zero.
- Avoid the phone, TV and game console because they reduce the remaining time.
- Watch out for the Deadline Monster as the deadline gets closer.
